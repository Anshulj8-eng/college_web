# 🎓 Alwar Education – Study Guide Website

This is a simple educational webpage project made using **HTML, CSS, and JavaScript**.  
It provides quick navigation for students to explore different courses (B.Tech, M.Tech, BA, B.Sc, etc.) and institutes in Alwar through clickable buttons, scrolling institute links, and a search feature.

---

## 🚀 Features

✅ Course buttons for quick redirection  
✅ Search bar to redirect based on course keywords  
✅ Scrolling institute marquee with clickable institute names  
✅ Basic UI layout with header, action bar, and content sections  
✅ Responsive-style structure (basic)

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (DOM + Events)**
